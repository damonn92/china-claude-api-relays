## 一、为什么需要中转

中国大陆开发者使用 Claude API 的现实门槛：

- **Anthropic 至今不接受中国大陆手机号注册**
- 海外信用卡被 Stripe / Anthropic 风控的概率持续走高
- 封号案例频繁，余额能否拿回视情况而定
- 即使有海外身份，IP / 设备指纹也可能被风控

中转服务的核心价值：把"账号风险 + 付款门槛"从你这边转嫁到运营方。

但中转市场鱼龙混杂——本指南目的就是帮你识别**真正稳的中转**。

## 二、选型决策框架（6 个硬指标）

任何中转，先用这 6 件事打分：

### 1. 是否按 Anthropic 官方价透传

> **红旗信号**：价格"0.3 折"、"5 折"、"远低于 Anthropic 官方"

按 Anthropic 官方价透传 = 你给客户报价时成本可预测。
价格异常便宜的，要么是用了被盗 / 共享 key（合规风险），要么靠"开始低、后期涨"套路你。

### 2. 余额是否永不过期 / 不强制订阅

> **红旗信号**：月费、订阅制、"未消费余额自动清零"

充值制 = 你账上的钱是你的。订阅制 = 你不用也得付。

### 3. 运营时长

> **红旗信号**：域名注册 < 3 个月，找不到运营主体

时间是中转最强的护城河。一个跑了 18 个月还在的服务，跑路风险显著低于跑了 3 个月的。

### 4. 退款政策

> **红旗信号**：无公开退款政策、"已充值不退"

正经服务都会写明：充值后 X 天内、未消费部分可全额退。

### 5. 工具兼容性

> **关键问题**：是否兼容 Claude Code / Cursor / Cline / Aider / Anthropic 官方 SDK / Hermes / Dify

最好同时支持 **Anthropic 原生协议** + **OpenAI 兼容协议** 两套。

### 6. 客服 / 工单响应

注册一个账号、提一个无关紧要的工单，看响应速度。
**24h 不回的，不用考虑。**

## 三、主流玩家逐一拆解

> 排序按字母，不代表推荐顺序。每家都有自己适合的人群。

### apirouter.ai

**定位**：境内服务器 + 企业级稳定性

**优点**：
- 境内节点延迟低
- 主打企业市场，对 SLA 比较看重
- 工单响应可

**局限**：
- 散户客户体验一般
- 注册和充值流程相对繁琐

**适合谁**：有 SLA 要求的企业团队

---

### CCFly / 类似低价站

**定位**：拼低价（如 "$0.01 起步"）

**优点**：
- 起步门槛极低，适合纯试水
- 接入文档基本齐全

**局限**：
- 价格异常的中转通常意味着合规和稳定性都未知
- 运营时长普遍偏短
- 跑路记录在所难免

**适合谁**：本指南**不推荐这一档**用于生产环境，仅作技术学习

---

### CloseAI

**定位**：老牌商业代理

**优点**：
- 运营时间较长
- 私域口碑沉淀
- 企业客户案例多

**局限**：
- 对外文档相对不开放
- 价格相对偏高

**适合谁**：愿意付溢价换稳定的中等规模团队

### PackyCode

**定位**：开发者圈老牌，Claude Code 深度优化

**优点**：
- 在 V2EX / 推特中文圈口碑深厚
- 缓存命中率高，对长 session 友好
- 多档 packg 选择，灵活
- 老用户基数大 = 跑路信任值最高之一

**局限**：
- 主打开发者，跨境业务场景理解一般
- 部分套餐为订阅制
- 对外文档对纯小白不算友好

**适合谁**：纯写代码的开发者、Claude Code 重度用户

---

### 七牛云 AI

**定位**：大厂背书 + 多模型聚合

**优点**：
- 七牛云作为知名 IaaS 厂商，企业可信度高
- 多模型支持（不止 Claude）
- 600 万 token 新用户额度（具体以官方为准）
- MCP 工具生态接入

**局限**：
- 不是纯 Anthropic 原生协议透传，部分 Claude 专属能力（如完整 thinking）受限
- 计费结构相对复杂

**适合谁**：企业要求"大厂背书"才能采购的场景

---

### 神马中转 API

**定位**：一把 key 调多模型

**优点**：
- 简单，注册快
- 多模型集成
- 知乎 SEO 流量大

**局限**：
- 透传逻辑相对不透明
- 部分用户反映高峰期稳定性波动

**适合谁**：早期玩家、对 Claude 专属能力不依赖的人

---

### 灵芽 API

**定位**：低延迟（宣传 40ms）+ 全模型

**优点**：
- 速度宣传较激进
- 知乎内容铺得多

**局限**：
- 极低延迟数字真假需要自测验证
- 公开运营信息相对有限

**适合谁**：对延迟敏感、且愿意自己跑测试的开发者

---

### 自建方案：CRS（开源）

**定位**：完全自己跑（你自己当中转）

**优点**：
- 没有第三方依赖
- 余额、key、所有数据都在你自己手里
- 适合学习 + 极客

**局限**：
- 你自己得有海外公司、海外卡、Anthropic 直连账号（最难的事还是没解决）
- 服务器、域名、工单都得自己来
- 不适合非技术背景的人

**适合谁**：技术背景 + 愿意承担运维成本的极客团队

## 六、独立验证方法（重要）

**不要信任何中转的口头承诺**，下面这些命令可以让你自己测。

### 6.1 透传计费验证

调一次官方文档里同样长度的 prompt，用同样的模型，对比官方计费。

```bash
# 对比标准
# Anthropic 官方价 (Sonnet 4)：input $3 / 1M tokens · output $15 / 1M tokens

curl -s https://[your-relay-domain]/v1/messages \
  -H "x-api-key: YOUR_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 100,
    "messages": [{"role":"user","content":"Repeat exactly: hello world"}]
  }' | jq '.usage'
```

记录返回的 `input_tokens` 和 `output_tokens`，去 dashboard 看扣了多少钱。
按官方价折算应等于扣费金额（汇率允许 ±2% 误差）。

### 6.2 延迟实测

```bash
for i in {1..10}; do
  time curl -s https://[your-relay-domain]/v1/messages \
    -H "x-api-key: YOUR_KEY" \
    -H "anthropic-version: 2023-06-01" \
    -H "content-type: application/json" \
    -d '{"model":"claude-haiku-4-5","max_tokens":10,"messages":[{"role":"user","content":"hi"}]}' \
    -o /dev/null
done
```

10 次平均 + 中位数 + p95，比单次测试可靠。

### 6.3 工具兼容性测试

```bash
# Claude Code
export ANTHROPIC_BASE_URL="https://[your-relay-domain]"
export ANTHROPIC_AUTH_TOKEN="YOUR_KEY"
claude "测试一下"

# Anthropic Python SDK
python3 -c "
from anthropic import Anthropic
c = Anthropic(base_url='https://[your-relay-domain]', api_key='YOUR_KEY')
r = c.messages.create(model='claude-sonnet-4-20250514', max_tokens=10, messages=[{'role':'user','content':'ping'}])
print(r.content)
"
```

### 6.4 退款流程验证

充 $5 → 立即（不消费）申请退款 → 看响应时间和到账时间。
**这是测试中转商最靠谱的方法之一**——能正常退的，不太可能跑路。

## 七、跑路风险识别清单

> 如果一个中转命中以下任何 ≥ 2 条，**强烈不推荐**充超过 $20。

- 🚨 价格"明显低于"Anthropic 官方价（如 0.3 折）
- 🚨 没有公开运营主体 / 公司信息
- 🚨 没有公开退款政策
- 🚨 域名注册 < 3 个月
- 🚨 工单 / 邮件 24h 内不回
- 🚨 微信群 / Telegram 群是唯一沟通渠道（没有正经工单系统）
- 🚨 没有 dashboard，按用量明细看不到
- 🚨 强制要求一次充值大额（> $100）
- 🚨 不接受任何形式的"测试 $5"
- 🚨 注册要求填写过多无关信息（身份证 / 工资单等）

## 八、贡献方式

### 修正错误

发现表里某项标错了？请 PR：

1. 在对应章节修改
2. 提供你的判断依据（截图 / 测试 log / 官方公告）

